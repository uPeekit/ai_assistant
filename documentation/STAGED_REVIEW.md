## How to read a case

Each bullet under a reader is one **action** it decided on — its final answer for the message,
after all its stages, before anything is written. A reader may decide several actions for one
message. Nothing below was actually written; this is what each reader *would* do.

These are the readers' answers *before* the last check against the vault, which both readers
go through: a book the staged reader looked up that you already have is dropped there (e18
lists «Чапаев и Пустота», which exists, so it would be left alone), and a "new note" named like
an existing one with properties becomes a change of those properties.

Only the staged reader can ask for a web search ("тело заполнит поиск в интернете"); the single
reader never searches the web, so for «найди …» it often answers with a search of your own notes
instead, which writes nothing.
